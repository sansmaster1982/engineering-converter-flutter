# Аудит Engineering Converter v5.7 (Kivy) — найденные ошибки

Дата: 17.09.2026. Проверялось: Android-сборка 5.7 (versionCode 202150700) на Samsung Galaxy S23 Ultra
(Android 16, 1080×2316), десктопный прогон `main.py` под Kivy 2.3.1 со скриптовым тестом (31 проверка),
статический разбор `main.py` и `IOS/main.py`. iPhone с этого ПК не был виден по USB (нет службы
Apple Mobile Device), поэтому iOS проверялась только по исходникам.

Легенда: 🔴 искажает результат расчёта, 🟠 мешает пользоваться, 🟡 косметика / расхождение версий.

## 1. Конвертер

| # | Ошибка | Как воспроизвести | Причина в коде |
|---|--------|-------------------|----------------|
| 🔴 1.1 | **SWAP портит значения.** | Давление, ввести `1`, Pa → kPa = 0.001. Нажать SWAP: поле становится `1000`, результат `1000000 Pa`. На десктопе 1 bar → Pa, SWAP → `1e-10`. Ожидалось: 0.001 kPa → 1 Pa. | `swap_units()` меняет спиннеры (каждая смена сразу пересчитывает результат), а уже потом копирует «результат» в поле ввода. |
| 🔴 1.2 | **Запятая молча выбрасывается.** Ввод `1,5` даёт `15` — ошибка в 10 раз. | Любое числовое поле, набрать `1,5` с русской клавиатуры. | `input_filter='float'` в Kivy пропускает только `.`; `replace(",", ".")` в коде никогда не срабатывает. |
| 🟠 1.3 | `0` показывается как `0.000000e+00`; 20 бар → Па даёт `2.000000e+06`; 1 Па → МПа даёт `1.000000e-06` (видно в таблице «All conversions»). | Ввести `0`, `20`, `1` в соответствующих единицах. | `format_float()`: научная запись при `<0.001` и `>1e6`, включая ноль. |
| 🟠 1.4 | Смена категории стирает результат, а число в поле остаётся. | Ввести `100`, сменить категорию. | `on_category_change()` в конце принудительно ставит `---`. |
| 🟠 1.5 | Для числовых полей открывается полная буквенная клавиатура. | Тап по любому полю. | У `TextInput` не задан `input_type='number'`. |
| 🟠 1.6 | Язык не сохраняется: приложение всегда стартует на английском. | Переключить RU, перезапустить. | `on_start()` читает `converter_settings.json`, но файл никто не пишет (экран «Сохранить настройки» удалён). |
| 🟡 1.7 | Подпись **«From:/Из:» не видна вообще**, «To:/В:» стоит по центру, а не над правым полем. | Главный экран. | `text_size=(Window.width, None)` у Label шириной 40 % — текст уезжает за край. |
| 🟡 1.8 | Шапка таблицы «Unit / Value» — белым по белому; полосы строк не рисуются. | Ввести любое число, смотреть таблицу. | Прямоугольник шапки рисуется один раз в позиции (0,0) и не обновляется (`_rebind_rect` пустой); фон строк стирается в `bind(pos=... canvas.before.clear())`. |

## 2. Инженерные расчёты

| # | Ошибка | Детали |
|---|--------|--------|
| 🔴 2.1 | **Расширительный бак: при t₁ > t₂ выдаёт отрицательный объём** («Расчётный объём −116.99 л, Рекомендуемый 5 л»). Нет проверки t₂ > t₁ и P₀ ≥ 0. | Проверяется только P₀ < Pmax. |

## 4. Расхождение Android и iOS

`main.py` и `IOS/main.py` — две копии одного файла на 1300+ строк, которые уже разошлись:

| Что | Android `main.py` | iOS `IOS/main.py` |
|-----|-------------------|-------------------|
| Единицы в RU | Pa, kPa, Steel… (не переведены) | Па, кПа, Сталь… |
| Материалы труб в RU | Steel/PPR/PEX/Copper | Сталь/ППР/PEX/Медь |
| Единицы в результатах RU | «m/s», «kW» | «м/с», «кВт» |
| Стальные трубы | до DN100 | до DN350 |
| Кнопка «Назад» в окнах | нет | есть |

Ошибка «концентрация показывается и для воды», о которой вы говорите, в сборке Android 5.7 на телефоне
не воспроизводится (окна «Тепловая мощность» и «Расширительный бак» открываются без строки концентрации).
В коде репозитория (обе копии, с первого коммита) поле добавляется только при выборе гликоля.
Скорее всего, у вас на iPhone стоит сборка, собранная раньше этой правки (в `TASK_FOR_NEW_CHAT.md` эта
ошибка описана для v5.5).

## 5. Репозиторий и безопасность

| # | Проблема |
|---|----------|
| 🟠 5.1 | `buildozer.spec` закоммичен вместе с паролем от keystore в открытом виде. Репозиторий `github.com/sansmaster1982/engineering-converter` сейчас закрытый (API отвечает 404), поэтому утечки нет, но если его когда-нибудь открыть, пароль уйдёт вместе с историей коммитов. Пароль лучше сменить (`keytool -storepasswd` / `-keypasswd`; сам ключ менять нельзя — RuStore привязан к нему) и вынести из spec в переменные окружения. |

| 🟡 5.3 | В корне 9 APK/AAB по 36 МБ, бэкапы `main_v54_backup.py`, `main_v55_backup.py`, `temp_screen*.png`, `nul`, `nul-` — мусор, который мешает ориентироваться. |

## 6. Что исправлено в новой Flutter-версии (`flutter_app/`)

- Один код для Android и iOS, расчёты вынесены в чистые Dart-функции (`lib/core/`) и покрыты тестами.
- SWAP делает обратный пересчёт корректно; ноль, большие и малые числа форматируются по-человечески
  (`2 000 000`, `0.000001`, научная запись только за пределами 1e−6…1e12).
- Ввод принимает и `,` и `.`; открывается цифровая клавиатура со знаком минус; в RU-локали
  результаты выводятся с запятой.
- Язык, тема и последняя категория/единицы сохраняются; стартовый язык берётся из системы.
- Расширительный бак проверяет t₂ > t₁, Pmax > P₀, P₀ ≥ 0; плотность воды по таблице от температуры.
- Трубы: сталь до DN350, пластик и медь подписаны «Ø20 × 3.4»; для введённого расхода показывается
  скорость сразу по всем типоразмерам с цветовой оценкой.
- Тепловая мощность и клапан работают в обе стороны (расход → мощность / мощность → расход,
  Q + Kvs → ΔP / Q + ΔP → Kvs).
- Полноценные экраны вместо всплывающих окон, поля не прячутся под клавиатурой, есть тёмная тема,
  результат копируется по нажатию.
